# No Worldborder Tint
No Worldborder Tint is a Minecraft mod that removes the red vignette tint when close to a world border.

Fabric versions of the mod 1.1.0+ use:
- [MoulConfig](https://github.com/NotEnoughUpdates/MoulConfig)
- [Fabric Language Kotlin](https://github.com/FabricMC/fabric-language-kotlin/)

Use `/noworldbordertint` (aliases: `/nwbt`, `/nwt`) or the config button through ModMenu to toggle the tint on or off. This is only for Fabric for now.
